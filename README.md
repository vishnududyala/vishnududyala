## 🙋‍♂️ About Me

I build backend systems that banks and fintech companies trust with real money and real customer data. I work across Java Spring Boot microservices, Python services in FastAPI and Django, and React frontends for account servicing, KYC, and loan workflows, backed by PostgreSQL, AWS, Redis, and Kafka. I care about the work that keeps systems safe, secure coding practices, real test coverage, and CI/CD pipelines that make releases boring instead of risky. I also evaluate LLM coding agents on large production codebases, scoring how well they reason through debugging, refactoring, and system design. MS in Computer Science from the University of Alabama at Birmingham.

## 📌 Pinned Projects

### Netcheck, Concurrent Network Health Checker
A Go CLI that checks network reachability across multiple targets in parallel using goroutines, cutting scan time by an estimated 5 to 10x versus sequential checks. Includes a CI/CD friendly interface with structured JSON output.

### AI Powered Code Review and Developer Productivity Assistant
A Python FastAPI backend using the OpenAI API and LangChain to generate review checklists and test suggestions for developers, with a React and TypeScript frontend, packaged in Docker with GitHub Actions CI checks and PyTest coverage.

### Data Insight Generator
A Python command line tool using the Anthropic Claude API and Pandas that turns any CSV file into business insights, trend analysis, and data quality observations.
